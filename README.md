Porto Verde — an original open-world crime game in the spirit of GTA 6, built for the make.fun gta6-01 bounty. Explore a sun-soaked port city on foot and by car, steal and drive cars, dodge the police as your wanted level rises, run missions for courier Luz Ferrer and fixer Rio Marín, fight, and save your progress. Three.js, procedural art, synthesised WebAudio sound and music — no commercial assets, everything original.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
